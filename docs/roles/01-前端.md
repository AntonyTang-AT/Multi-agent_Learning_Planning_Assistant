# 1 号 · 前端职责说明书

> 关联：[五人分工总览](../五人分工与细化落地说明.md) · [项目文件结构](../项目文件结构.md) · [技术路线](../技术路线与方案.md)  
> 代码目录：`frontend/`

---

## 1. 定位

负责 **Web 学习助手界面**：期末复习 / 跟课补漏两场景入口、对话、计划、练习、资料浏览、黑板与用户裁决卡片。  
**只调用 2 号后端 API**；不直连 LLM，不写 Agent 逻辑。

---

## 2. 做什么 / 不做什么

| 做 | 不做 |
|---|---|
| 页面、交互、加载/错误态 | 提示词、Agent 编排 |
| 按 API 展示计划/题目/黑板 | 本地伪造「智能判断」当真逻辑（Mock 仅开发用） |
| 演示动线与演示控制条 UI | 持有 API Key |
| 响应式（笔记本答辩为主） | 原生 App |

---

## 3. 页面与模块

| 模块 | 路径建议 | 说明 | 优先级 |
|---|---|---|---|
| 场景入口 | `/` | 选期末复习 / 跟课补漏，填考试日或当前章节、每日时长 | P0 |
| 对话 | `/chat` | 发消息；展示系统回复与 `user_options` | P0 |
| 计划 | `/plan` | 读已存计划；冲突选项提交裁决 | P0 |
| 练习 | `/practice` | 选题、作答、展示通过/提示/弃答 | P0 |
| 资料 | `/materials` | 按学科/章/场景标签浏览 | P1 |
| 轨迹 | `/trace` | 作答记录、简单掌握度 | P1 |
| 黑板 | 侧栏或 `/blackboard` | 条目列表与 resolve | P0 |
| 演示 | 高级区 | 时间跳跃等，调后端 demo | P0 |

---

## 4. 技术约定（已锁定）

- **React 18 + Vite + TypeScript + Ant Design 5 + React Router 6 + Axios + Zustand**  
- UI：简洁学习产品风；答辩投屏可读。  
- `VITE_API_BASE` / `VITE_USE_MOCK`；开发期 Mock 走完主路径。  
- 逐日任务见 [`docs/五人详细任务计划.md`](../五人详细任务计划.md) §1。

---

## 5. 依赖的后端能力

见 `backend` 的 `docs` / OpenAPI。至少：

- `POST /api/ai/{intent}` — 智能转发结果展示  
- 计划 / 题目 / 作答 / 黑板 / 资料查询 CRUD  

收到 `status: conflict|abstain|need_user` 时按约定组件渲染，不自行改计划。

---

## 6. 12 号验收

- [ ] 两场景入口可填约束并进入主流程  
- [ ] 无 AI 时：浏览资料、看已存计划、做题存记录可走通（依赖 2 号）  
- [ ] 有 AI 时：同一套 UI 能展示冲突选项与弃答  
- [ ] 演示操作路径可 3 分钟内点完

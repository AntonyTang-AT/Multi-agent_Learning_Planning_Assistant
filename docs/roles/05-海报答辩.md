# 5 号 · 海报 / PPT / 答辩职责说明书

> 关联：[五人分工总览](../五人分工与细化落地说明.md) · 考核要求（用户提供）  
> 材料目录：`poster/` · `pitch/`

---

## 1. 定位

负责考核叙事与材料：用户需求分析、至少两种方案比较、A2 海报、答辩 PPT、3 分钟路演稿、演示控场衔接、协助每人准备个人面试「贡献 1 分钟」。  
不扛核心编码；材料必须与 1/2/3/4 真实交付一致。

---

## 2. 考核对齐清单

| 要求 | 落点 |
|---|---|
| 用户需求分析 | 期末复习 + 跟课补漏痛点；访谈/问卷要点 |
| ≥2 种方案比较 | 可行性/实用性/创新性/安全/成本 → 选定本方案 |
| 核心功能展示 | 与演示脚本对齐；海报放架构与截图 |
| A2 PDF 海报 | `poster/项目海报_A2.pdf` |
| 3 分钟结构 | 问题与用户 → 方案 → 演示 → 创新安全改进 |
| 团队合作可说明 | 分工表、接口合同、进度节点 |

---

## 3. 双场景痛点（写作提纲）

- **期末**：时间紧、资料散、计划拍脑袋、对答案不放心  
- **跟课**：当堂没懂、作业卡住、补漏无序、越学越难  

收集 5–10 条同学原话即可，海报用 3 条。

---

## 4. 方案比较（建议表）

| 维度 | A 单模型聊天复习 | B Web 学习站 + 独立多智能体校验协商（本方案） |
|---|---|---|
| 可行性 | 高 | 中（壳核分离后清晰） |
| 实用性 | 能问，计划与答案可信度弱 | 可审计、可弃答、可落库 |
| 创新性 | 低 | 质疑/校验/黑板/用户裁决 |
| 安全风险 | 幻觉直出 | AI 封装门禁 |
| 实现成本 | 低 | 中（MVP 已裁剪） |

---

## 5. 海报（A2）块面

1. 标题 + 一句话创新  
2. 双场景用户痛点  
3. 架构：前端 ↔ 传统后端 ↔ AI 内核 I/O  
4. 五机制缩略 / 三必演  
5. 成果截图  
6. 安全与边界  
7. 团队分工  

---

## 6. PPT（8–10 页）与口播

页序：封面 → 问题 → 方案比较 → 架构 → 创新点 → 演示说明 → 安全改进 → 分工致谢。  

口播约 450–500 字/3 分钟；演示段标注「【1 号操作】」。超时优先砍比较细节，**不砍演示**。

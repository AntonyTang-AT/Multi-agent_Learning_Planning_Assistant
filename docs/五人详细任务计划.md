# 五人详细任务计划

> 技术栈已锁定，见 [技术路线与方案 §2](./技术路线与方案.md)。  
> 分人职责：[roles/](./roles/)  
> **时间轴**：以「现在 → **12 号检查点** → 答辩」三段推进。若 12 号实为更晚日期，同一任务按周拉伸，顺序不变。  
> 假设从启动日起约 **2 周到 12 号**（例如 10/30→11/12）；更宽裕则每周做下表两天的量。

---

## 0. 总进度闸门

| 闸门 | 日期意向 | 全组必须同时满足 |
|---|---|---|
| **G0 开工** | 第 1 天 | 栈锁定已读；仓库目录齐；三人能分别 `npm`/`uvicorn` 空跑 |
| **G1 合同** | 第 2–3 天 | `api.md` + `agent-api.md` 字段冻结一版；样例 JSON 可拷贝 |
| **G2 传统站** | **12 号** | 无 Agent 也能：选场景、浏览资料、存计划、做题落库 |
| **G3 智能通** | 12 号后约 1 周 | 冲突协商 + 校验弃答 可录屏 |
| **G4 答辩冻** | 答辩前 3 天 | 三必演固定用例；海报 PDF；讲稿彩排 |

**站会**：每 2–3 天 20 分钟——只对接口变更、演示能否复现、谁被堵。

## 1 号 · 前端 —— 详细任务

**栈**：React 18 + Vite + TS + Ant Design 5 + React Router + Axios + Zustand  

### 里程碑

| 里程碑 | 完成标准 |
|---|---|
| F1 | `npm run dev` 有布局与路由空页 |
| F2 | Mock 走通：场景 → 计划冲突选项 → 黑板 |
| F3 | 接真后端：资料/计划/作答 |
| F4 | 接 AI 网关：冲突/弃答真数据 |
| F5 | 演示模式与 3 分钟操作路径稳定 |

### 按日/阶段任务

**第 1–2 天**

- [ ] `npm create vite@latest`（React-TS），装 `antd` `react-router-dom` `axios` `zustand`
- [ ] 配 `.env`：`VITE_API_BASE`
- [ ] 布局：顶栏 + 内容区；路由：`/` `/chat` `/plan` `/practice` `/materials` `/blackboard`
- [ ] `src/types/api.ts` 按 `docs/api.md` / agent 响应摘一版类型

**第 3–5 天（Mock 优先）**

- [ ] `ScenarioWizard`：期末 / 跟课；表单字段（考试日或章节、每日分钟、科目）
- [ ] `PlanPage`：任务列表；`UserOptionsCard`（三选项）
- [ ] `BlackboardPanel`：条目列表 + resolve 按钮
- [ ] `PracticePage`：题干、提交、展示 passed/abstain
- [ ] `src/mocks/*.json` 使用 `agent/examples` 改编；`VITE_USE_MOCK=true` 开关

**第 6–9 天（接 2 号）**

- [ ] `api/client.ts`：拦截器、错误 Toast
- [ ] 接 `session` `materials` `questions` `plans` `attempts` `blackboard`
- [ ] 无 AI 主路径联调（12 号闸门）

**第 10 天–12 号**

- [ ] UI 打磨（投屏字号、中文文案）
- [ ] 演示控制条 UI（可先绑 Mock）
- [ ] 自测清单打勾；问题记到群里

**12 号之后**

- [ ] `POST /api/ai/{intent}` 真接；冲突/弃答联调
- [ ] DemoBar：`time-jump`、展示 force 开关（若后端提供）
- [ ] 与 5 号合写并演练 `docs/演示脚本.md`
- [ ] 答辩前冻结页面，不加人功能

### 依赖与同步

- 堵在后端：用 Mock，不闲置  
- 类型变更：跟 2 号同一天改 `types`  

### 面试贡献一句话

独立完成学习助手 Web 与演示操作链路，保证壳在智能未就绪时仍可展示。

## 2 号 · 后端 —— 详细任务

**栈**：FastAPI + SQLAlchemy 2 + SQLite + Pydantic v2 + httpx  

### 里程碑

| 里程碑 | 完成标准 |
|---|---|
| B1 | `/api/health` 绿；OpenAPI `/docs` 可开 |
| B2 | 资料导入 + 题目/材料查询 |
| B3 | 计划/作答/黑板 CRUD |
| B4 | `agent_client` 可调 8001（失败有码） |
| B5 | AI 响应落库；demo 接口 |

### 按日/阶段任务

**第 1–2 天**

- [ ] `venv` + `requirements.txt`：`fastapi uvicorn sqlalchemy pydantic httpx python-dotenv`
- [ ] `app/main.py` 挂路由；CORS 放行 `5173`
- [ ] `models`：User, KnowledgeNode, Material, Question, Plan, Attempt, BlackboardEntry, AiCallLog(可选)
- [ ] `GET /api/health`；`POST /api/session`

**第 3–5 天**

- [ ] `services/import_data.py` 读 `data/taxonomy` + `data/questions`
- [ ] `GET /api/materials` `GET /api/questions`（支持 subject/chapter/scenario_tag）
- [ ] 写 `docs/api.md` 与实现同步
- [ ] 单元/手工：导入样例后查询非空

**第 6–8 天**

- [ ] plans / attempts / blackboard 的 GET/PUT/POST
- [ ] resolve 更新 status/resolution
- [ ] 与 1 号联调无 AI 路径（**12 号核心**）

**第 9–12 号**

- [ ] `services/agent_client.py`：超时、`agent_unavailable`
- [ ] `POST /api/ai/{intent}`：转发 → 写 AiCallLog/黑板/计划草稿 → 返回
- [ ] Agent 未启动时前端仍能用 CRUD（不要 500 整站挂死）

**12 号之后**

- [ ] `demo/time-jump`；必要时缓存「上次成功 AI 快照」供演示
- [ ] 导入 4 号扩容后的数据包回归
- [ ] 答辩前 DB 备一份 `demo.db` 种子

### 纪律（防越界）

- 禁止在 backend 写提示词 / SymPy /「自动消冲突」  
- 只维护 `AGENT_BASE_URL`，不放 LLM Key（默认）

### 面试贡献一句话

传统学习站 API 与数据落库，并完成与 AI 服务的安全解耦转发。

## 3 号 · 多智能体 —— 详细任务

**栈**：FastAPI + intent 路由 + Worker 模块 + DeepSeek + SymPy（CrewAI 可选，不挡验收）  

### 里程碑

| 里程碑 | 完成标准 |
|---|---|
| A1 | `/health` + `/agent/v1/invoke` 回声 |
| A2 | `create_plan` + **规则审计冲突** + user_options |
| A3 | `verify_answer` / 出题链路 + **弃答** |
| A4 | 错因策略差异；黑板条目齐全 |
| A5 | 固定演示用例 100% 可复现 |

### 按日/阶段任务

**第 1–2 天**

- [ ] 独立 `agent` 应用；`.env.example`：`DEEPSEEK_API_KEY` `MODEL_NAME`
- [ ] `schemas/request.py` `response.py` 按技术路线冻结
- [ ] `invoke`：未知 intent 返回明确错误；`echo` 调试意图可删

**第 3–6 天（计划链路 P0）**

- [ ] `workers/planner.py`：规则/模板生成任务列表（可先少调 LLM）
- [ ] `rules/plan_audit.py`：超时、缺完成标准、先修；`demo.force_conflict`
- [ ] 冲突时写 `blackboard_entries` + `user_options`
- [ ] `arbitrate`：按 option_id 重排或降级说明
- [ ] 更新 `examples/create_plan_*.json` 与真响应一致

**第 7–10 天（校验链路 P0）**

- [ ] `workers/verifier.py`：SymPy；`force_verify_fail`
- [ ] `workers/generator.py`：优先基于 `resource_payload` 改编题；失败走弃答
- [ ] `status=abstain` 文案与 `audit_trail`
- [ ] 供 2 号联调的稳定端口与 README

**第 11–12 号**

- [ ] 错因 → 策略表（规则字典即可）
- [ ] 保证：**无 Key 时**规则演示仍可跑（LLM 调用降级为模板）
- [ ] 与 2 号对一次 create_plan / verify

**12 号之后**

- [ ] Evaluator 质疑（缺假设样例对接 4 号题）
- [ ] 元认知 / 主动干预模板卡片
- [ ] 负荷信号读取 `trace_snapshot`（有则用）
- [ ] 答辩三用例脚本化（一条命令或固定 request 文件）
- [ ] （可选）CrewAI 包装，不改 I/O

### 面试贡献一句话

实现可校验、可质疑、可协商的多智能体内核，并保持稳定 I/O 封装。

## 4 号 · 资料 —— 详细任务

**形态**：宽大纲 JSON + 题包 + 场景标签 + 校验脚本  

### 里程碑

| 里程碑 | 完成标准 |
|---|---|
| D1 | 高数+大物章级大纲齐 |
| D2 | 双场景标签可用；样例可导入 |
| D3 | ≥30 高数 + ≥15 大物（舒适区）；校验题与质疑题就绪 |
| D4 | README 版权与导入说明终版 |

### 按日/阶段任务

**第 1–3 天**

- [ ] 按本校课表改 `taxonomy/math_outline.json` `physics_outline.json`（章名对齐教材）
- [ ] 定 `scenario_tags` / `exam_hot` / `lecture_week` 填写规范（半页写入 `data/README.md`）
- [ ] 扩展 `math_sample.json` 到 ≥8 题；补 `physics_sample.json` ≥5 题
- [ ] 跑通 `validate_schema.py`

**第 4–8 天**

- [ ] 按章扫：课件要点元数据（`materials/`，每章至少 1 条）
- [ ] 习题录入：优先填 `verify_hint`、错因、期末热点
- [ ] `exams/`：真题元数据或拆题 ≥1 套高数（能检索即可）
- [ ] 交 2 号可导入的一包 v0.1（**赶 12 号**）

**第 9–12 号**

- [ ] 跟课包：给 2–3 个 `lecture_week` 聚合（`catch_up/` 或标签齐全）
- [ ] 期末包：`exam_hot=true` 可筛出一列复习题
- [ ] 缺假设质疑样例 ≥2；错因种类 ≥4

**12 号之后**

- [ ] 题量拉到舒适区；大物补迁移章
- [ ] 与 3 号对验收：校验题、冲突演示用的知识点覆盖
- [ ] 冻结数据包版本号（如 `data v1.0`），答辩不临时改 ID

### 面试贡献一句话

建成可按期末/跟课筛选的结构化课程数据层，支撑软件导入与智能演示。

## 5 号 · 海报 / PPT / 答辩 —— 详细任务

### 里程碑

| 里程碑 | 完成标准 |
|---|---|
| P1 | 双场景痛点 + 双方案比较表定稿 |
| P2 | 海报线框评审 |
| P3 | A2 PDF 可提交；PPT+路演稿可彩排 |
| P4 | 三分钟 + 演示衔接不超时 |

### 按日/阶段任务

**第 1–4 天**

- [ ] 访谈/问卷 ≥5 人（期末复习、跟课补漏各问）
- [ ] 写出痛点 3 条原话级素材
- [ ] 方案 A/B 比较表（可行性/实用/创新/安全/成本）
- [ ] 与 3 号对一下创新表述，避免海报写代码没有的功能

**第 5–10 天**

- [ ] 海报线框（A2 七块：见 roles/05）
- [ ] PPT 大纲 8–10 页
- [ ] `pitch/路演稿.md` 初稿 + 秒表分节
- [ ] 收 1/2/3/4 的「个人贡献」各 3–5 句，写入备忘

**第 11–12 号**

- [ ] 用现有 UI/架构图更新线框（可先截 Mock）
- [ ] 检查评分点：需求、比较、创新、分工均有着落

**12 号之后**

- [ ] 真机截图替换：冲突、弃答、黑板
- [ ] 出 `poster/项目海报_A2.pdf`
- [ ] PPT 终稿；全员彩排 ≥2 次
- [ ] 演示脚本与口播对齐；准备 1–2 个评委追问应答（安全、数据是否合成、与 ChatGPT 区别）

### 面试贡献一句话

完成需求分析与方案论证，统筹海报与三分钟叙事，并对齐真实功能。

## 2. 进程与端口（建议）

| 服务 | 目录 | 建议端口 | 负责人 |
|---|---|---|---|
| 前端（React+Vite+TS+AntD） | `frontend/` | `5173` | 1 |
| 后端（FastAPI+SQLite） | `backend/` | `8000` | 2 |
| 多智能体（FastAPI+Workers+DeepSeek+SymPy） | `agent/` | `8001` | 3 |

任务排期见 [五人详细任务计划](./五人详细任务计划.md)。

前端 `VITE_API_BASE=http://localhost:8000`  
后端 `AGENT_BASE_URL=http://localhost:8001`

## 3. 依赖方向（禁止反依赖）

```text
frontend  →  backend  →  agent
backend  →  data（导入）
agent    →  仅通过请求体中的 resource 文本/refs 工作
             （若同机只读 data/，须在 README 写明，避免双真相）
pitch/poster 不依赖代码，但截图来自运行中的 frontend
```
